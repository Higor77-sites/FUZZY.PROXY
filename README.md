# FUZZY PROXY - MOD MENU

Projeto web completo em arquivo único (`index.html`), pronto para hospedagem estática (Netlify, Vercel, GitHub Pages, Hostinger ou servidor local).

## Como usar
1. Extraia o arquivo `index.html`.
2. Abra diretamente no navegador ou suba para o seu serviço de hospedagem.
3. Na tela de login, utilize a chave: `FUZZY-PROXY-AIM99` (ou clique em **GET KEY**).
4. Selecione os módulos desejados e digite manualmente um código numérico de 6 dígitos para confirmar a conexão.
